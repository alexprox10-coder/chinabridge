# Smart Pricing Engine v1.1

## Обзор

Smart Pricing Engine автоматически выбирает правило наценки для каждого заказа на основе:
- Веса груза
- Типа клиента
- Типа транспорта
- Категории груза

Результат: цена клиента, прибыль, маржа — рассчитываются автоматически при каждой заявке.

---

## Архитектура

```
Rate Engine (базовая ставка)
        ↓
   carrier_cost (себестоимость)
        ↓
Cost Engine → selectPricingRule()
        ↓
   sale_price = carrier_cost × (1 + markup%)
        ↓
   profit = sale_price − carrier_cost
   margin = profit / sale_price × 100
        ↓
Telegram Notification (📊 Pricing block)
```

## Структура правила `PricingRule`

| Поле | Тип | Описание |
|------|-----|---------|
| `id` | number | Авто-инкремент |
| `name` | string | Название (напр. "Standard Consolidation") |
| `rule_type` | `markup \| margin \| discount` | Тип расчёта |
| `value` | number | Процент наценки/скидки |
| `status` | `active \| inactive` | Активно ли правило |
| `min_weight` | number? | Мин. вес для применения (кг) |
| `max_weight` | number? | Макс. вес (исключительно) |
| `customer_type` | `B2C \| SMALL_BUSINESS \| BUSINESS \| VIP`? | Тип клиента |
| `transport_type` | string? | Тип транспорта (null = любой) |
| `cargo_type` | string? | Тип груза (null = любой) |
| `priority` | number? | Приоритет (1 = высший) |

## Типы клиентов

| Тип | Описание |
|-----|---------|
| `B2C` | Розничный клиент, мелкие заказы |
| `SMALL_BUSINESS` | Малый бизнес, средние объёмы |
| `BUSINESS` | Корпоративный клиент, крупные объёмы |
| `VIP` | VIP-клиент, специальные условия |

## Алгоритм выбора правила

```
selectPricingRule(input):

1. ЕСЛИ customer_type == VIP:
   → Взять правило с customer_type=VIP (игнорировать вес)
   → Вернуть VIP правило

2. ИНАЧЕ:
   → Отфильтровать активные правила по весу:
     rule.min_weight <= weight < rule.max_weight
   → Дополнительно фильтровать по customer_type (если задан)
   → Дополнительно фильтровать по transport_type (если задан)
   → Сортировать по priority (возрастание)
   → Взять первое (наивысший приоритет)

3. ЕСЛИ подходящих правил нет:
   → Базовая наценка 20% (fallback)
```

## Формулы

### Markup (наценка на себестоимость)
```
sale_price = carrier_cost × (1 + value / 100)
profit     = sale_price − carrier_cost
margin     = profit / sale_price × 100
```

### Margin (наценка на итоговую цену)
```
sale_price = carrier_cost / (1 − value / 100)
profit     = sale_price − carrier_cost
margin     = value  (напрямую)
```

### Discount (скидка)
```
sale_price = list_price × (1 − value / 100)
```
