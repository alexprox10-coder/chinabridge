## How to use
- Before proposing new features: check `current-quarter.md` to validate alignment with Q3 goals.
- Before starting a week's work: read `weekly-priorities.md` for P0 tasks.
- When making a non-obvious technical choice: add an ADR to `decisions.md`.
- When a KPI is hit: mark it done in `current-quarter.md`.
