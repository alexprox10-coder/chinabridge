# ChinaBridge — Библиотека промптов для Apify

> Используй эти промпты в **Claude Desktop** с подключённым Apify MCP.
> Подставляй текущую дату вместо [дата].

---

## ПРОМПТ 1 — Продавцы Wildberries (активные)

```
Используй Apify чтобы найти 50 активных продавцов на Wildberries
в категориях: одежда, электроника, товары для дома, автозапчасти.

Для каждого продавца собери:
- Название магазина
- Количество товаров
- Email если есть
- Ссылка на магазин

Сохрани результат в таблицу CSV.
Файл: leads/wb-sellers-[дата].csv
```

## ПРОМПТ 2 — Оптовые магазины Алматы (Google Maps)

```
Используй Apify Google Maps Scraper.

Запрос: "оптовый магазин" в городе Алматы, Казахстан.
Дополнительно: "wholesale store Almaty"

Для каждого места собери:
- Название
- Телефон
- Адрес
- Сайт
- Email если есть
- Рейтинг и количество отзывов

Лимит: 100 результатов.
Сохрани в: leads/almaty-wholesale-[дата].csv
```

## ПРОМПТ 7 — Instagram аудитория конкурентов

```
Используй Apify Instagram Scraper.

Найди аккаунты которые подписаны на эти аккаунты:
- @b2bchina (конкурент — доставка из Китая)
- @chinaopt (оптовики из Китая)

Собери подписчиков у которых в bio есть слова:
"оптом", "wholesale", "бизнес", "магазин", "ИП", "ТОО"

Для каждого:
- Username
- Имя
- Bio
- Количество подписчиков

Лимит: 200 аккаунтов.
Сохрани в: leads/instagram-competitors-[дата].csv
```

## ПРОМПТ 8 — Персонализация сообщений (после сбора базы)

```
У меня есть таблица с контактами компаний (прикреплю CSV).

Для каждой компании напиши персонализированное сообщение
по шаблону ChinaBridge.

Учитывай:
- Название компании (обращайся по названию)
- Категорию товаров
- Город (упомяни маршрут доставки в их город)

Формат вывода:
Компания | Телефон | Персонализированное сообщение

Стиль: деловой, короткий, без пафоса. Максимум 5 строк.
CTA всегда: chinabridge.pro
```
