## Инструкция по персонализации

1. Возьми CSV с лидами
2. Выбери нужный шаблон по категории
3. Замени `[категория]` на реальную категорию компании
4. Используй ПРОМПТ 8 из `prompt-library.md` для массовой персонализации через Claude

**Правило:** не отправляй одно и то же сообщение дважды одному контакту.
Отмечай статус в Supabase: `new → contacted → interested → client`
